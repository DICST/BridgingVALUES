Apresentação

Dados territoriais para comunidades e gestores

Esta página disponibiliza para as instituições e comunidades locais os relatórios e publicações vinculados ao Projeto BridgingVALUES no Brasil, além dos mapas interativos e dados espaciais gerados para a região do Mosaico de Unidades de Conservação do Boqueirão da Onça.

O atlas digital (mapas interativos e dados espaciais) foi desenvolvido pelo INPE em resposta a uma demanda das próprias comunidades, definida de forma participativa em oficinas realizadas na região. A iniciativa busca fortalecer atores locais por meio do acesso ao conhecimento e da organização de informações sobre o território.

O conteúdo está organizado em diferentes camadas de informação e temas, permitindo a visualização dos dados espaciais de forma simples e integrada. Além disso, é possível aplicar filtros e realizar o download dos dados espaciais para uso em ferramentas de geoprocessamento (SIG).

"O projeto envolveu oficinas, mapeamento de atores e construção coletiva de soluções, buscando compreender conflitos, identificar caminhos futuros e propor ações que conciliem a conservação da biodiversidade com a equidade social."

— Equipe do projeto

Conheça a equipe responsável pelo projeto

Projeto BridgingVALUES

O Atlas foi desenvolvido no contexto do projeto internacional BridgingVALUES, que investiga como as políticas e estratégias globais de conservação da biodiversidade impactam os territórios locais — considerando que esses efeitos variam entre diferentes regiões do mundo.

O projeto adotou uma abordagem participativa e interdisciplinar, com estudos de caso em seis países, incluindo o Brasil. A pesquisa brasileira foi conduzida no mosaico de áreas protegidas do Boqueirão da Onça (BA).

Guia Rápido

Como usar o Atlas

Instruções para consulta dos mapas e download dos dados espaciais.

🗺️ Consultando os Mapas Interativos

  1. 1

    Na seção Mapas Interativos, clique no botão "Abrir Mapa" do tema desejado;

  2. 2

    O mapa abrirá em uma nova aba do navegador com todas as camadas disponíveis;

  3. 3

    Clique no ícone de informação à direita (i) para ler a descrição sobre o mapa;

  4. 4

    Clique no ícone de camadas à direita (em azul) para ativar ou desativar as camadas sobre o tema;

  5. 5

    Dê zoom e clique sobre os elementos do mapa para ver informações detalhadas sobre os atributos das camadas na área selecionada;

  6. 6

    Utilize a legenda para interpretar as cores e símbolos de cada camada.

⬇️ Baixando os Dados Espaciais

  1. 1

    Na seção Dados Espaciais, use a barra de busca para encontrar o dado de interesse;

  2. 2

    Cada linha corresponde a uma camada (shapefile) ou projeto do QGIS (.qgz);

  3. 3

    Baixe todos os arquivos do mesmo nome ou o arquivo zip (clicando em "Baixar tudo"). No caso do shapefile, as extensões .shp, .dbf, .shx e .prj são indispensáveis;

  4. 4

    Para abrir os projetos do QGIS corretamente, coloque todos os arquivos (shapefiles e projetos) em uma mesma pasta;

  5. 5

    Os projetos do QGIS permitem visualizar as camadas por tema com a simbologia organizada pela equipe do projeto;

  6. 6

    Você também pode abrir os shapefiles em outro software de SIG de sua preferência, mas as simbologias não serão preservadas.
